1. ПРОВЕРИТЬ УСТАНОВКУ
git --version

2. НАСТРОЙКА (один раз)
git config --global user.name "Твоё Имя"
git config --global user.email "твой@email.com"

3. СОЗДАТЬ РЕПОЗИТОРИЙ
git init
// В папке появится скрытая папка .git

4. ПРОВЕРИТЬ СОСТОЯНИЕ
git status

5. ДОБАВИТЬ ФАЙЛ В ИНДЕКС
git add readme.md      // конкретный файл
git add .              // все файлы сразу

6. СДЕЛАТЬ КОММИТ
git commit -a -m "Текст сообщения"
// Кавычки обязательны с двух сторон

7. ИСТОРИЯ КОММИТОВ
git log
// Нажми Q чтобы выйти

8. ПОСМОТРЕТЬ ИЗМЕНЕНИЯ
git diff

9. ПЕРЕКЛЮЧИТЬСЯ НА СТАРУЮ ВЕРСИЮ
git checkout <номер_коммита>

10. ВЕРНУТЬСЯ К ПОСЛЕДНЕЙ ВЕРСИИ
git checkout master

MARKDOWN (readme.md)
**текст**   - жирный
*текст*     - курсив
~~текст~~   - зачёркнутый
# текст     - заголовок 1
## текст    - заголовок 2
1. пункт    - нумерованный список
* пункт     - ненумерованный список
  * пункт   - вложенный список

ВАЖНО
Git отслеживает файлы по имени!
Переименовал файл — снова git add + git commit
Стрелка вверх в терминале повторяет предыдущую команду.
